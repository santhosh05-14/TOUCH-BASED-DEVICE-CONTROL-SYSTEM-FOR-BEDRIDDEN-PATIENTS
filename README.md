# TOUCH-BASED-DEVICE-CONTROL-SYSTEM-FOR-BEDRIDDEN-PATIENTS
Touch-Based Device Control System for Bedridden Patients using LPC2124 ARM7 Microcontroller. Enables patients to control devices through a touch interface with password authentication, EEPROM-based data storage, LCD feedback, keypad input, UART communication, SPI EEPROM, and interrupt handling.
